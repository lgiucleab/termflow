## As built (2026-11-22)

### Deviations from the plan
- **rusqlite 0.41** instead of 0.43: `rusqlite_migration` 2.7 requires `^0.41` (two `libsqlite3-sys` versions can't link together).
- **`jiff` instead of `chrono`** for timestamps: `cargo deny` flags chrono as unmaintained (RUSTSEC-2026-0543; jiff is a recommended replacement). Only `ErrorClass` uses it so far.
- Small utility deps not listed in §2 were added: `ulid`, `jiff`, `regex`, `schemars`, `tempfile` (dev). TypeScript is 7.x (the native compiler); `tsc --noEmit` works unchanged.
- The TOML config holds only `ui`, `terminal`, `updates` sections for now; other sections arrive with the features that need them.
- Bindings are regenerated by `cargo test -p termflow-desktop export_bindings` (and every debug launch); CI fails if the checked-in file changed (`git diff --exit-code`). Same for `schemas/termflow.schema.json`.
- Clippy pedantic is on; `unwrap`/`expect` are denied except in tests (`clippy.toml`). One crate-level allow in `src-tauri` (`needless_pass_by_value`, required by `tauri::State`).
- All crates are `publish = false`.

### Verified locally (macOS arm64)
- Full §14.3 suite green: fmt, clippy `-D warnings`, 14 Rust tests, `cargo deny`, Biome, `tsc`, vitest (1 test).
- `pnpm -C apps/desktop tauri build --debug` produced `TermFlow.app` (47 MiB debug) and `TermFlow_0.1.0_aarch64.dmg` (11 MiB).
- The launched app shows "Version 0.1.0" via the typed bridge and the counter increases (Rust → UI events). The DB was created with WAL; the log file was written.

- Read connections aren't pooled (one per call). The pool comes when M2 adds read traffic.
- The demo ticker (`start_ticker`, `AppEvent::Tick`) is M0 scaffolding and will be removed once real events exist.
